## 🧪 PhyAnim – 计算/存储/渲染分离的物理动画引擎

**后端**：`scipy` · `heyoka`

一个完全代码驱动的、事件导向的物理动画框架。  
你只需声明物理对象、方程和事件，引擎会自动求解并渲染出精确的科普动画。
